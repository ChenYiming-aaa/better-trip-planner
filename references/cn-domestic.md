# cn-domestic — 景区预约与实名制速查（境内游第一雷区）

> 境内-only 版专用。SKILL.md Phase 4 的 "official venue site first" 在国内场景下
> **指向本文件**：热门景区几乎全部"预约制 + 一人一证一票"，临时到了门口进不去
> 是国内游计划最真实的翻车方式。本文的放票时刻与渠道为编写时点（2026）的通行
> 规则，**每次计划仍须按 data-sources.md 的阶梯复核**——放票时间随季节调整很常见。

通用规则：
- **渠道只认官方**公众号/小程序/官网——OTA（美团/携程）卖的是"代预约+溢价"，且
  同样要身份证号，不是捷径。
- 周一闭馆是全国博物馆的默认设置（法定节假日除外）——Phase 4 排 day 时先对表。
- 放票即抢节假日票：行程日期确认后，**把"开售日 20:00 提醒"写进 checklist**
  （deadline 用 `T-N` 格式，`route_tools ics` 会生成日历事件）。

## 2. 实名制

- 一人一证一票：**每个入园人的身份证号都要提前收**（儿童户口本号同样可用）。
  Phase 0 intake 就问清出行人证件信息是否齐备，不要等到 Phase 4 出票。
- 入园普遍"刷身份证原件"——电子身份证（支付宝/微信网证）大部分场馆可用，
  但港澳台居民/外籍人士走人工通道，预留排队时间。
- 高铁/机票已全程实名，与门票证件保持**同一人同一证**，改签/退票才不扯皮。
- 优惠票（学生/老人/儿童）规则各馆差异大且普遍**现场核验证件**：计划里只写
  "凭有效证件半价，现场核验"，不替用户承诺具体折扣。

## 3. 门票与开放时间的复核阶梯

1. 官方公众号/小程序（放票规则、临时闭馆公告第一发布位）；
2. 美团/大众点评门票页（**实价与库存**比官网更实时，但预约规则以官方为准）；
3. 电话核实（官网页脚的咨询电话，旺季临时管控最可靠）。

## 4. 把 KML 坐标批量转成高德收藏点

国内用户几乎不用 KML；`route_tools kml` 产出的 `trip.kml`（WGS84 坐标，高德
服务端会自动纠偏显示）可以这样使用：

- **高德地图 App**：收藏夹不支持直接导入 KML。用本目录的逐点链接代替——
  `route_tools links` 输出的每条 amap 链接在手机浏览器打开后点"收藏"即可入夹。
- **批量方案**：`trip.kml` 导入 **Organic Maps / 奥维互动地图**（离线可用，
  渲染页 footer 的"离线地图"提示即为此口径）；奥维原生支持 KML 图层。
- 计划页上已有逐跳 + DAY CHAIN（via= 驾车概览）深链，游客侧通常无需再导 KML。

## 5. 高德 key 免费申请（首次使用提示接入者）

**高德开放平台对个人开发者完全免费**（支付宝扫码实名认证后，地理编码/路径规划/
POI 搜索/天气查询均在个人免费配额内——行程规划类用量绰绰有余；只有商用大规模
调用才需要购买配额包）。**检测到未配置 `AMAP_KEY` 时，在首次 geocode 前向用户
提示本节三步**；用户配置前流程不阻塞（百度回退/手工坐标仍可出计划）。

1. 打开 [lbs.amap.com](https://lbs.amap.com) → 右上角"控制台" → 注册/登录
   （短信即可）→ **个人开发者认证：支付宝扫码**，提交即过；
2. 控制台 → 应用管理 → **创建新应用**（名称随意，类型选"出行"）→ 该应用下
   **添加 Key** → 服务平台务必选 **「Web 服务」**（不是 JS API/Android）→ 提交；
3. 复制生成的 Key，写入环境变量并重开终端：
   `setx AMAP_KEY <你的key>`（Windows）/ `export AMAP_KEY=<你的key>`（macOS/Linux）。
   也可写入 skill 根目录的 `.env`（`AMAP_KEY=<你的key>` 一行即可，route_tools 自动
   读取；该文件已被 .gitignore 排除——仓库里有可复制的 `.env.example` 模板）。

注意：Web 服务 key 与 JS API key 不通用，选错类型会鉴权失败；key 是私密凭据，
**不要**提交进仓库或写进计划文件/文档（新 key 试运行期间可能偶发
`CUQPS_HAS_EXCEEDED_THE_LIMIT`，脚本已自动重试一次，仍失败等几秒重跑即可）。
若 key 意外泄露，到高德控制台**重置该 key** 即可作废旧值。
